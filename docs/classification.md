# Appliance classification (task 1.3)

Generated by `scripts/05_classify.py`. Modeling population: 33,927 customers (185 labeled EV, 87 labeled HP, 396 PV list).

**Method.** Flags come from *physics gates* (equipment ratings in `src/avangrid/classify.py`). EV and HP also get a *PU logistic ranking* (labeled vs unlabeled, 5-fold out-of-fold scores) used to rank customers and grade confidence. Labels are used only as checks, never to set a threshold.

**SCAR-implied precision.** If the labeled customers are a random c = 25% of true owners (the brief), then among any flagged group the labeled share should be 25% x precision. So precision ≈ labeled share / 0.25. This is only valid if SCAR holds, which the checks below question.

## EV

- Elkan-Noto estimate of c from the data: **0.035** vs 0.25 in the brief. With c = 0.25, the Elkan-Noto rule (g/c ≥ 0.5) flags 235 (c=0.15), 111 (c=0.25), 43 (c=0.4) customers versus ~744 implied. **The check fails**: labeled EVs are not separable enough from the rest for SCAR + c = 0.25 to hold, consistent with the 44% of labeled EVs that show no home-charging signature (docs/data_checks.md). ## Heating type and heat pumps

- PU logistic CV AUC **0.762** (fold s.d. 0.043); benchmark 0.738.
- Elkan-Noto c from the data: **0.011** vs 0.25; flags at c = 0.25: 7 vs ~352 implied. Same conclusion as EV: ranking only.

Heat type from the *shape* of the temperature response: electric if heat slope ≥ 0.5 kWh/day/°F; HP if the slope steepens ≥1.25x below 20 °F, HP+backup if it at least doubles; resistive if linear and ≥ 1.5; otherwise electric (type unclear).

## Solar PV

Rule: summer-minus-winter midday zero share ≥ 0.1 (zeros follow the sun) and summer night zeros < 0.05 (not vacant). Against the complete PV list: precision **92.0%**, recall **90.2%**, F1 **0.911**. Flagged but not on the list (unregistered PV candidates): **31**. Listed but not flagged: 39 (small systems that never export, or a different meter configuration).

PV homes that also read 0 kWh in ≥30% of summer 17-21h hours (a battery covering the evening): **5**. Metering is delivered-only, so PV generation and self-consumption are invisible; these counts are lower bounds.
