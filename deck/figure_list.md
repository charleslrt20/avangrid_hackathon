# Deck figure set (task 3.1)

All figures are in `docs/figures/`. They are 200 dpi PNGs regenerated by `bash scripts/run_all.sh`. They use the
Okabe-Ito colour-blind-safe palette (`src/avangrid/plots.py`): summer = vermilion, winter = blue,
reference = grey. App screenshots come from `python app/screenshots.py` (customer IDs hidden).
Every number in a title or label is computed from `outputs/`; the "source" column says which table backs it.

Order follows PLAN.md §3.2: problem → data → method → findings → BESS → value → future → roadmap.
